Component Specifications & Accessibility

Keyboard Navigation Map
  • Tab / Shift+Tab: Sequential focus navigation
  • Enter / Space: Toggle mega menu panel
  • Escape: Close panel and restore focus to trigger button
  • ArrowLeft / ArrowRight: Navigate top-level items
  • ArrowDown: Enter dropdown panel
ARIA State Attributes
  • aria-expanded="true|false" on triggers
  • aria-haspopup="true" on menu buttons
  • aria-controls="panel-id" associating panels
  • role="menubar" & role="menuitem" semantics
  • aria-hidden="true|false" on dropdown panels
Interaction Polish & Tokens
  • Intent hover debounce (120ms timeout prevents accidental closing)
  • CSS design tokens for light and dark themes
  • GTM dataLayer events on open, click, and search
  • Mobile offcanvas drawer with focus trapping
